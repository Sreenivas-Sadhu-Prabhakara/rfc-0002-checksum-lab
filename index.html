Read RFC 2 ↗Status & errata ↗

RFC 2 discusses adding fixed-size fields and folding an overflow carry into the low end. It also suggests an order-dependent extension. This lab implements only the basic 8-bit folding sum, so swapping two bytes can leave the sum unchanged.

The visible collision is the lesson: a quick error check can be useful without proving that data is unchanged or authentic. Try a bit flip and a swap to see the difference.

Not the full proposed grouped, shifted checksum and not a modern integrity or security tool. Equal sums can hide changes. The archived RFC reports a missing first page. Official index status: UNKNOWN (Legacy stream). This project is independent of the RFC Editor and IETF.
